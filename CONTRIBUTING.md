# Contributing to Airview

Report reproducible issues with the app version, Windows version, steps, expected behaviour and actual result. Remove personal information from screenshots and logs. Never publish API keys or tokens.

Keep changes focused, follow the README build instructions, run npm test and npm run build, and visually verify interface changes with missing data and reduced motion. Use English for maintained source comments, documentation and interface text.

Respect provider licences, attribution, cache requirements and quotas. Do not add paid services without an explicit maintainer decision. Always label calculated positions, estimated flight phases and indicative routes. Airview is not an operational aviation tool.
