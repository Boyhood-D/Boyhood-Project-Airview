# Contribuer à Airview

Merci de contribuer à une application gratuite pour les passionnés d’aviation et d’espace.

## Signaler un bug

Créer une issue avec la version d’Airview, la version de Windows, les étapes pour reproduire, le résultat attendu et le résultat obtenu. Masquer toute donnée personnelle dans les captures ou journaux. Ne jamais publier de clé API ni de jeton.

## Proposer un changement

Décrire le problème et la solution dans une issue ou une pull request. Garder les changements ciblés et préciser la validation effectuée. Respecter les licences, quotas et conditions des fournisseurs ; ne pas ajouter de service payant sans décision explicite du mainteneur.

## Vérifier

Suivre les commandes du README. Exécuter `npm test` et `npm run build` pour les changements de code. Vérifier visuellement les changements d’interface, y compris les animations réduites et les données manquantes.

Les phases, routes et positions calculées doivent toujours être identifiées comme telles. Ne pas présenter Airview comme un outil opérationnel de navigation ou de contrôle aérien.
